Linux Backup

Linux Backup is a personal, non-commercial tool that creates encrypted backups of the owner's Ubuntu computer and stores them in the owner's own Google Drive.

It uses the open-source programs rclone and restic. Backups are encrypted on the computer before upload, with a key that only the owner holds.

The app requests only the https://www.googleapis.com/auth/drive.file scope, so it can access only files and folders that it created itself.
