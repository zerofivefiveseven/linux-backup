Privacy Policy

Last updated: November 9, 2026

Linux Backup is a personal backup tool used only by its owner. This policy describes how it handles data accessed through Google APIs.

Data accessed

The app uses the Google Drive API with the drive.file scope. It can read and write only the files and folders it has created in the signed-in user's Google Drive. It does not access other Drive files, email, contacts, or any other Google data.

How data is used

The app uploads encrypted backup archives of the user's own computer to the user's own Google Drive and downloads them back for verification and restore. Data is encrypted on the user's computer before upload.

Storage and sharing

OAuth tokens are stored only on the user's computer in files readable by the user and the system administrator. No data is sent to the developer or to any third party, and no data is sold, used for advertising, or used to train AI models. The app has no server.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Backup files can be deleted from Google Drive by the user at any time.
